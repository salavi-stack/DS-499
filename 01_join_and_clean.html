Building My Analysis Dataset

Gender Gaps in Internet Access and Economic Outcomes

Shukria Alavi

September 25, 2026

My research question

Does a smaller gender gap in internet access go together with better economic outcomes for women in developing countries?

I look at three outcomes: GDP per capita, female labour force participation, and female secondary school enrollment.

What I want to know at this stage:

  1. How big is the internet gender gap, and how much does it vary between countries?
  2. Do I have enough complete data to compare it against my three outcomes?

internet  <- read_csv("data_raw/source1_internet_gender_findex.csv",

Dataset 1: Internet use by gender

Source: World Bank Global Findex 2025. Gallup surveyed adults aged 15 and over in each country between May and December 2024 and asked whether they use the internet. Every country was surveyed in the same year with the same question, which is why I use this as my main measure.

The published file is 8,577 rows by 438 columns covering six survey years and every breakdown. 00_download_sources.R narrows it to 2024, the gender breakdown, and the internet question, and converts the values from proportions to percentages.

This gives me my independent variable.

This is the most important check on the page. 14 countries are spelled differently between the two organisations. The World Bank writes “Egypt, Arab Rep.” where the UNDP writes “Egypt”, and “Kyrgyz Republic” where the UNDP writes “Kyrgyzstan”.

If I had joined on country name, those 14 countries would have silently dropped out and I would never have known. This is why I join on the three-letter country code, which is standardised across organisations.

Step 3: Joining

left_join keeps every row on the left and adds matching columns from the right. Where there is no match it fills in NA instead of dropping the row.

I start from the internet data, because a country with no gender gap measure is no use to me.

data <- internet %>%
  left_join(outcomes,   by = "country_code") %>%
  left_join(inequality, by = "country_code")

data <- data %>%

Step 4: Cleaning

Each decision below says what I did and why.

Build the gender gap variable

The gap is not in any dataset. I calculate it from the male and female columns.

data <- data %>%
  mutate(
    gap_diff  = internet_men - internet_women,   # percentage points; + means men ahead
    gap_ratio = internet_women / internet_men    # 1.0 means equal
  )

Droping Kosovo

Kosovo is missing female labour force participation, overall internet use, and the Gender Inequality Index. That is most of what I need. R would exclude it from nearly every model anyway, so removing it on purpose keeps my stated sample size honest.

data <- data %>% filter(country != "Kosovo")
nrow(data)
## [1] 89

Add a logged GDP column

GDP per capita is skewed, with a few countries much richer than the rest. Taking the log evens it out, which is standard before using it in a model.

data <- data %>% mutate(log_gdp = log(gdp_pc_ppp))

Keep the columns I actually use

data <- data %>%
  select(country_code, country,
         internet_women, internet_men, gap_diff, gap_ratio,
         gdp_pc_ppp, log_gdp, flfp, sec_enroll_fem_gross,
         internet_total, urban_pct, gender_inequality_index)

What I did NOT do
