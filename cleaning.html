Cleaning

Step 1: Drop Kosovo

Kosovo is missing female labour force participation, overall internet use, and the Gender Inequality Index. That is most of what I need, so I remove it rather than letting R quietly drop it later.

data <- data %>%
  filter(country != "Kosovo")

nrow(data)
## [1] 95

Step 2: Keep only the columns I need

The file has 37 columns and I only use about a dozen. I keep those and give the enrollment column a shorter name.

data <- data %>%
  select(
    country,
    region,
    income,
    source,
    ref_year,
    internet_female,
    internet_male,
    gap_diff,
    gap_ratio,
    gdp_pc_ppp,
    flfp,
    enroll_fem = sec_enroll_fem_gross,
    internet_total,
    urban_pct,
    gii
  )

dim(data)
## [1] 95 15

Step 3: Add a logged GDP column

GDP per capita is skewed, with a few countries far richer than the rest. Taking the log evens it out, which is standard before using it in a model.

data <- data %>%
  mutate(log_gdp = log(gdp_pc_ppp))

Step 4: Turn region and income into categories

Right now these are text. Making them factors tells R they are categories.

data <- data %>%
  mutate(
    region = factor(region),
    income = factor(income,
                    levels = c("Low income",
                               "Lower middle income",
                               "Upper middle income"))
  )

A first look at the data

How big is the gender gap?

ggplot(data, aes(x = gap_diff)) +
  geom_histogram(bins = 20, fill = "steelblue", colour = "white") +
  geom_vline(xintercept = 0, linetype = "dashed") +
  labs(title = "Internet gender gap",
       x = "Male % minus female % (percentage points)",
       y = "Number of countries")
